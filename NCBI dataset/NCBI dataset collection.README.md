# Dataset Collection

In this project, I explored the NCBI GEO database and selected the GSE348919 dataset for practice in biological data analysis. The dataset is related to preinvasive breast cancer and contains gene expression data from spatial transcriptomics.

## Database Used
- NCBI Gene Expression Omnibus (GEO)

## Dataset Details
- Accession Number: GSE348919
- Organism: Homo sapiens
- Data Type: Spatial transcriptomics
- Platform: Illumina NovaSeq 6000

## Work Done
- Searched for a suitable biological dataset
- Checked the dataset information and sample details
- Downloaded sample files for further analysis

This work helped me learn how to find and collect biological datasets for bioinformatics practice.
