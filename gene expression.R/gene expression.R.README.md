# Gene Expression Data Analysis using R

This is a basic data analysis project using R. I used a gene expression dataset to check its structure, data quality, and summary statistics. I also created a boxplot to see the distribution of gene expression values across samples.

## Tools Used
- R programming
- CSV dataset
- Basic data visualization

## Analysis Performed
- Checked dataset dimensions and column names
- Inspected the data structure
- Checked missing values and duplicate rows
- Counted negative and zero values
- Calculated summary statistics
- Created a boxplot of gene expression values

## What I Learned
This project helped me practise basic R programming and understand how to inspect, check, summarize, and visualize biological data.
