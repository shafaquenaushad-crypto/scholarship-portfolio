# NCBI BLAST Practice

This is a beginner-level project where I practised using NCBI BLAST to compare DNA sequences and understand sequence similarity.

## Tools Used
- NCBI BLAST
- NCBI Nucleotide Database

## Work Done
- Searched DNA sequences using accession numbers
- Compared sequences using BLASTN
- Observed sequence identity, query coverage, and E-value
- Reviewed the BLAST results to understand sequence similarity

## What I Learned
This practice helped me understand how BLASTN is used to compare DNA sequences and interpret basic results in bioinformatics.
