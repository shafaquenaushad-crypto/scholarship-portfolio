# Biological Data Analysis using Python

## About the Project

This is a beginner-level project in which I worked with a biological dataset to learn how biological data can be analyzed using Python.

I used a dataset from NCBI GEO related to breast cancer. The project helped me understand how to work with biological data files and perform basic data analysis.

## Objective

The main objective of this project is to learn how to handle biological data, understand its basic structure, and summarize the data using Python.

## Dataset

- **Source:** NCBI Gene Expression Omnibus (GEO)
- **Dataset ID:** GSE348919
- **Organism:** Homo sapiens
- **Data type:** Spatial transcriptomics and gene expression data
- **Platform:** Illumina NovaSeq 6000

## Tools and Libraries Used

- Python
- Pandas
- Matplotlib
- SciPy
- Gzip
- Glob

## What I Did

- Explored the downloaded biological data files.
- Used Python to locate and read the required files.
- Practiced working with gene expression data.
- Performed basic data analysis.
- Created a graph to present the results.

## What I Learned

Through this project, I learned how to work with biological data files, use Python libraries, organize data, and present information through a graph. I also gained a better understanding of how programming can be used in biological research.

## Conclusion

This project was a learning experience that helped me practice basic Python programming and explore biological data. I am still learning and plan to improve my data analysis skills through more projects.
