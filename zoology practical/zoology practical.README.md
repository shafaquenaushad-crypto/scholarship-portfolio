# Life Science Practicals

This folder contains practical work related to Life Science, including earthworm measurements, DNA sequence analysis, phylogenetic analysis, and PCR primer design.

## Practicals Included

### 1. Earthworm Pre- and Post-Clitellar Length
Measurements of 5 earthworms, including calculation of mean, median, mode, and standard deviation.

### 2. Sequence Analysis Using NCBI BLAST
Downloading a gene sequence from NCBI and understanding BLAST results, including query details, sequence alignment, and similarity.

### 3. Phylogenetic Analysis Using PHYLIP
Learning the basic concepts of phylogenetic analysis and the steps involved in multiple sequence alignment and distance matrix calculation using Dnadist.

### 4. PCR Primer Design
Using a gene sequence from NCBI to design PCR primers and examining four candidate primer pairs generated by Primer3.

## Purpose

The purpose of these practicals is to understand basic biological data analysis and learn how to use bioinformatics tools for sequence analysis and primer design.
