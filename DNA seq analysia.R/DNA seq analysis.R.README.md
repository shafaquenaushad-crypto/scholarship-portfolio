# DNA Sequence Analysis using R

This is a basic DNA sequence analysis project using R. It counts the A, T, G, and C bases in a DNA sequence and finds its complementary and reverse sequences.

## Tools Used
- R programming
- Basic R functions

## What I Learned
- Working with DNA sequences in R
- Counting nucleotides
- Finding complementary DNA sequences
- Understanding reverse sequences

This project helped me practice basic R programming and learn how it can be used for biological data analysis.
